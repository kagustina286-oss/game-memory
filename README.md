# Juego de Memoria 🃏

Juego de memoria desarrollado con HTML, CSS y JavaScript vanilla como proyecto de práctica.

## ¿Cómo se juega?
- Hacé click en una carta para darla vuelta
- Encontrá su par antes de que se acabe el tiempo
- Ganás cuando encontrás los 8 pares

## Características
- 16 cartas con imágenes
- Temporizador de 40 segundos
- Contador de movimientos
- Contador de aciertos

## Tecnologías
- HTML5
- CSS3
- JavaScript
